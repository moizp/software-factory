CLAUDE CODE CONFIGURATION (.claude/)
------------------------------------
.claude/CLAUDE.md           - Main orchestrator instructions for the factory workflow
.claude/settings.json       - Claude Code configuration (model, MCP servers, tools)

AGENTS (.claude/agents/)
------------------------
.claude/agents/analyzer.md
  - Reads project brief and config
  - Extracts requirements, features, MCP needs
  - Outputs structured JSON spec

.claude/agents/mcp-configurator.md
  - Validates credentials exist
  - Registers MCP servers with Claude Code
  - Tests connections
  - Lists available tools for builders

.claude/agents/architect.md
  - Creates system design and diagrams
  - Generates database schema (Prisma/TypeORM)
  - Writes API contracts (OpenAPI spec)
  - Designs deployment architecture

.claude/agents/builder.md
  - Generates production code using MCP tools
  - Uses backend/frontend/infrastructure patterns
  - Commits code to GitHub via GitHub MCP
  - Creates tests

.claude/agents/reviewer.md
  - Runs test suite (unit, integration, E2E)
  - Security scanning and vulnerability checks
  - Code quality validation
  - Gates deployment

SCRIPTS (scripts/)
------------------
setup-mcp.sh                - Bash script to auto-configure MCP servers
                             (GitHub, PostgreSQL, Stripe, etc)
                             Run: ./scripts/setup-mcp.sh

validate-mcp.sh             - Tests all configured MCP servers
                             Verifies connections and credentials
                             Run: ./scripts/validate-mcp.sh

credentials.sh.template     - Template for API keys and secrets
                             Copy to credentials.sh and fill in real values
                             NEVER commit credentials.sh

DOCUMENTATION (docs/)
----------------------
mcp-setup-guide.md          - Detailed MCP configuration reference
                             - Getting GitHub, Stripe, Database tokens
                             - Local vs hosted databases
                             - Troubleshooting connection issues
                             - Security best practices

HOW TO USE
==========

1. INITIAL SETUP
   cp scripts/credentials.sh.template scripts/credentials.sh
   Edit with your API keys (GitHub, Stripe, Database)
   source scripts/credentials.sh

2. VALIDATE SETUP
   ./scripts/setup-mcp.sh
   ./scripts/validate-mcp.sh

3. CONFIGURE PROJECT
   Edit project.config.json with your project details

4. RUN FACTORY
   claude "Execute complete factory workflow"

FACTORY WORKFLOW
================

INPUT: project.config.json
        ↓
   ANALYZER
   (extracts requirements)
        ↓
   MCP CONFIGURATOR
   (wires external services)
        ↓
   ARCHITECT
   (designs system)
        ↓
   BUILDERS (parallel)
   (backend, frontend, infrastructure)
        ↓
   REVIEWER
   (tests, security, QA)
        ↓
OUTPUT: Production code in GitHub

CUSTOMIZATION
=============

To extend the factory:

1. Add new agent: Create .claude/agents/your-agent.md
2. Add new skill: Create .claude/skills/your-skill.md
3. Add MCP server: Update project.config.json mcp_servers
4. Add builder: Modify .claude/agents/builder.md workflow

All changes are designed to be project-agnostic and reusable.
